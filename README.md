# Laboratorio Comercial UTEL

Prototipo React + Vite para entrenamiento comercial de Psicología Organizacional.

## Contenido
- Portada con identidad UTEL y Mejora Continua.
- Seis módulos navegables.
- Comparación de enfoques organizacional y clínico.
- Diagnóstico, método 5C y laboratorio de objeciones.
- Reto comercial de práctica con respuestas y retroalimentación.
- Formulario de demostración y vista previa del certificado.
- Logos originales y ficha técnica en `public/assets`.

## Ejecutar
Requiere Node.js. Ejecuta `npm install` y luego `npm run dev`.
Para compilar: `npm run build`.

## Importante
Esta es una base frontend. El registro solo vive en la sesión actual: no hay base de datos, autenticación, emisión real de PDF ni verificación de certificados. Antes de emitir certificados oficiales se debe conectar almacenamiento seguro, definir los criterios de aprobación, generar un identificador verificable y revisar el tratamiento de datos personales.

El PDF fuente incluye Psicología Clínica como asignatura. Eso no demuestra por sí solo una habilitación profesional específica en Colombia. Verifica con el área académica toda afirmación comercial sobre alcances profesionales.
